# Local companion memory checks

Run `dotnet run --project tests/Kitty.Memory.Tests -c Release`.

Tests cover read-only initial loading, bounded atomic saves, aggregate traits and
personality, semantic positive memories, quantized observation context, expiry of
old context, read-only last-good recovery, preserved unknown future profiles,
corrupt/future/locked files, independent profiles and complete reset. A pure
gesture check distinguishes slow strokes from hovering, rapid waving and dragging.
Files use random temporary test profiles; personal kitty memory is untouched.
